# MathLab в Telegram Mini Apps

Адрес приложения: **https://67n48zds75-ui.github.io/-/**.

Клиентская часть уже поддерживает Telegram. GitHub Pages подходит для размещения Mini App: он обслуживает готовое приложение по HTTPS. Для кнопки запуска нужен Telegram-бот, которым управляет владелец проекта. Привязка бота в BotFather — отдельный шаг, её нельзя считать выполненной только после публикации кода.

## Подключение с телефона без токена

Откройте официального [@BotFather](https://t.me/BotFather) в Telegram.

Если бота ещё нет:

1. Отправьте `/newbot`.
2. Укажите название, например `MathLab — олимпиадная математика`.
3. Выберите свободный username, заканчивающийся на `bot`. Доступность имени определяет Telegram.
4. Полученный токен храните у себя. Для описанной ниже настройки его не нужно помещать в приложение, публичный репозиторий или чат.

Для существующего или только что созданного бота:

1. Отправьте BotFather команду `/setmenubutton`.
2. Выберите своего бота.
3. На запрос адреса приложения отправьте ровно `https://67n48zds75-ui.github.io/-/`.
4. На запрос названия кнопки отправьте `Открыть MathLab`.
5. Откройте личный чат с ботом и нажмите кнопку меню. Если нужно, сначала нажмите «Начать».

Действия и названия запросов BotFather могут меняться: ориентируйтесь на сообщение бота. Не отправляйте URL репозитория `github.com/...` — Mini App должен открывать сайт `github.io/-/`.

## Кнопка в профиле и прямая ссылка

Дополнительно в BotFather откройте `/mybots` → свой бот → **Bot Settings → Configure Mini App → Enable Mini App** и укажите тот же HTTPS-адрес. Это настройка **Main Mini App**. Она добавляет кнопку запуска в профиль бота.

После включения Main Mini App можно использовать ссылку:

```text
https://t.me/ИМЯ_ВАШЕГО_БОТА?startapp
```

Здесь `ИМЯ_ВАШЕГО_БОТА` заменяется настоящим username без символа @. Ссылка не заработает как Main Mini App, пока соответствующая настройка не выполнена в BotFather. Настройка только `/setmenubutton` включает кнопку чата, но сама по себе не включает Main Mini App.

Прямой переход по HTTPS-ссылке в сообщении Telegram может открыть обычный браузер Telegram. Для нативных функций запускайте приложение через Mini App-кнопку бота или настроенный `?startapp`.

## Что реализовано

- Официальный SDK `telegram-web-app.js` подгружается в head при обнаружении параметров запуска Telegram; обычная браузерная версия не зависит от этой загрузки. При недоступности SDK приложение остаётся в браузерном режиме, ожидание ограничено 7 секундами.
- `ready()` и `expand()` инициализируют интерфейс. Полноэкранный режим принудительно не включается.
- Светлая/тёмная тема следует Telegram и событию `themeChanged`. При этом сохранённая тема обычной версии не перезаписывается настройкой Telegram.
- Системные и контентные безопасные отступы учитываются при изменении viewport и ориентации.
- Нижние вкладки дают доступ к главной, задачам, прогрессу и профилю. Олимпиада доступна через кнопку с кубком в верхней панели.
- Нативная кнопка «Назад» закрывает CSV, текущую задачу или итоги, а из раздела возвращает на главную. Закрытие задачи учитывается теми же правилами, что и в браузерной версии.
- При незавершённой задаче/олимпиаде включается системное подтверждение закрытия, если клиент поддерживает его. Это не восстанавливает незавершённый ввод после закрытия.
- Правильный и неправильный ответ дают нативный тактильный отклик, если он доступен и разрешён устройством.
- CSV в Telegram доступен как текст с копированием. Если устройство поддерживает отправку локальных файлов через Web Share API, появляется «Поделиться файлом». При запрете буфера обмена текст выделяется для ручного копирования. История никуда не загружается для получения ссылки на файл.
- При выходе обработчики SDK снимаются. Отсутствующие или неподдерживаемые методы старых клиентов не должны ломать тренажёр.

## Данные и ограничения

Прогресс сохраняется в LocalStorage данного WebView и origin. Между обычным браузером, разными устройствами и разными Telegram-клиентами синхронизации нет. При очистке данных WebView история может исчезнуть. Совместный компьютер или несколько аккаунтов в одном общем хранилище не получают раздельные профили по Telegram ID. История не является защищённым экзаменационным результатом.

Собственный код MathLab не читает `initDataUnsafe`, не сохраняет Telegram ID, имя или контакты и не использует Telegram launch-параметры как авторизацию. Определение контекста служит только для оформления и нативных элементов. Если появятся серверный профиль, рейтинги или запись результатов от имени пользователя, сервер должен проверять подпись `initData`, срок действия и права пользователя по официальной схеме Telegram.

Для текущего статического тренажёра backend и токен бота не нужны. Бот без собственного backend не отправляет текстовый ответ на `/start`, но настроенные Mini App-кнопки позволяют запускать тренажёр. Не добавляйте токен в переменные `VITE_*`: их содержимое попадает в публичную сборку.

SDK Telegram — внешний скрипт, загружаемый только при Mini App-запуске. Сам Telegram SDK обрабатывает данные запуска в своём контексте; MathLab не использует их для профиля или отправки результатов. При блокировке `telegram.org` используйте обычную браузерную версию. После загрузки страницы расчёты задач остаются локальными.

## Проверка перед демонстрацией

Автоматические тесты используют имитацию SDK и JSDOM. Они проверяют загрузку, fallback, события, отписку, темы, кнопку назад, предупреждение о закрытии и CSV. Они не заменяют проверку в настоящих Telegram iOS/Android/Desktop.

На реальном устройстве после настройки бота проверьте:

- запуск через Mini App-кнопку и наличие нижних вкладок;
- смену темы Telegram и поворот экрана;
- поле ответа при открытой клавиатуре, подсказки и разбор;
- нативную кнопку назад и закрытие незавершённой задачи;
- копирование CSV и доступность отправки файла;
- сохранение завершённых решений после повторного открытия;
- обычную браузерную версию по прежней ссылке.
