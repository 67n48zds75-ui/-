# MathLab — адаптивный тренажёр олимпиадной математики

Рабочее приложение для индивидуального проекта 10 класса: React + TypeScript, Vite, Tailwind CSS 4, Recharts, KaTeX. Серверная база данных, платные API, ключи и регистрация не нужны.

## Запуск на Windows

1. Установите **Node.js 24 LTS** с npm (также поддерживается Node.js от 22.13).
2. Распакуйте проект. Откройте терминал в папке `mathlab`, где лежит `package.json`.
3. Выполните:

```powershell
npm ci
npm run dev
```

Откройте адрес, показанный Vite (обычно **http://localhost:5173**). Не открывайте `index.html` двойным щелчком: приложению нужен локальный веб-сервер. Для остановки нажмите Ctrl+C. Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd ci` и `npm.cmd run dev` либо обычную командную строку Windows.

Для проверки и готовой сборки:

```powershell
npm test
npm run build
npm run preview
```

`npm run preview` показывает содержимое `dist` (обычно http://localhost:4173). Интернет нужен для первой установки npm-пакетов. Шрифты и формулы входят в сборку; приложение не обращается к внешним сервисам во время тренировки. Service Worker не используется: это не устанавливаемое офлайн-PWA.

## Что работает

- Главная с настоящими показателями, персональным подбором и рекомендациями.
- Каталог из **62 задач**: по 10 базовых в каждом из 6 разделов и 2 дополнительных с несколькими ответами. Из 60 базовых две имеют выбор одного ответа, остальные — числовой.
- Фильтры по разделу, сложности 1–10 и поиск по тексту.
- Числовой ответ, выбор одного варианта, несколько правильных вариантов.
- Последовательные три подсказки, завершение попытки и пошаговый разбор с ключевой идеей.
- Адаптивная тренировка, повторение выбранного раздела, ежедневная подборка до пяти завершений в день.
- Олимпиада: пять задач, двадцать минут, без подсказок. По истечении времени текущая задача отмечается неуспешной; ещё не открытые не считаются решёнными.
- Графики правильных завершений по дням, освоения разделов и уникальных решённых задач по сложности; история сессий.
- Уровни, текущая серия и четыре достижения. Полученная награда за серию сохраняется и после следующей ошибки.
- CSV с русскими заголовками, разделителем `;` и UTF-8 BOM для Excel.
- Светлая/тёмная темы, мобильная навигация, клавиатурное управление, фокус внутри диалога, закрытие Escape, поддержка уменьшения анимаций.

Задачи сформулированы для проекта на основе стандартных математических приёмов; тексты из олимпиадных сборников не импортировались. Некоторые задачи намеренно вводные: они помогают новичку освоить приём перед более сложными заданиями. Оценки 1–10 относительные и авторские, требуют калибровки преподавателем; уровень 10 не означает сложность финала всероссийской олимпиады.

## Адаптация простыми словами

Это прозрачный алгоритм правил, а не нейросеть. Он может объяснить свой выбор.

1. Для каждого раздела берём последние 8 завершённых задач.
2. Ошибка даёт 0 баллов. Верное завершение даёт `max(0.2, 1 − 0.15 × подсказки − 0.15 × (попытки − 1))`.
3. Среднее этих баллов, умноженное на 100, — оценка освоения темы. Без данных показывается 0%, что означает «пока не изучено», а не доказанный пробел.
4. Приоритет получают разделы с меньшим освоением. При равенстве — менее изученные.
5. Начальная сложность в теме — 2. Три последних верных решения без подсказок и повторных ответов повышают её на 1. Последняя ошибка снижает на 1. Остальные случаи сохраняют сложность последней задачи. Границы: 1–10.
6. В первую очередь берём ещё не решённую задачу ближайшей сложности. Если вся тема решена, предлагаем повторение. Поэтому при исчерпании задач фактическая сложность может отличаться от целевой.

Например, три самостоятельных решения на сложности 2 дают цель 3. Ошибка на сложности 3 даёт цель 2. Успех с двумя подсказками не повышает цель и добавляет только 0.7 к освоению.

Общий уровень — `min(10, 1 + floor(число уникальных решённых задач / 6))`. Это показатель активности, он отличается от целевой сложности в отдельной теме. Процент правильных ответов считается по завершённым попыткам решения; промежуточные ошибки сохраняются как число попыток и снижают освоение.

## Проверка ответа и данные

Числа допускают `7`, `0,4`, `0.4`, `65/8`, отрицательные дроби. Ограничение — 80 символов. Ввод должен целиком соответствовать формату числа или дроби; арифметические выражения, JavaScript, деление на ноль и бесконечности отвергаются. Для чисел используется абсолютная погрешность менее `1e-8`. В задачах с несколькими вариантами проверяется точное множество выбранных ответов.

Данные хранятся только в `localStorage`, ключ `mathlab-v1`: завершённые результаты, число попыток и подсказок, время, режим, случайный ID сессии и тема оформления. Имя, контакты и другие персональные данные не запрашиваются. История ограничена последними 5000 записями; экран решений показывает последние 30, экран сессий — последние 8. CSV экспортирует всю сохранённую историю.

Завершённые результаты и тема переживают закрытие браузера. Незавершённый ввод и таймер активной сессии не восстанавливаются после перезагрузки. Закрытие карточки после ошибки/подсказки завершает её неуспешно; пустая открытая карточка не влияет на статистику. При ошибке LocalStorage появляется предупреждение, приложение продолжает работать в памяти.

Каждый браузер, порт и адрес сайта имеют собственное хранилище. Не меняйте адрес для демонстрации сохранения. Очистка данных сайта/приватный режим могут удалить историю. Общий компьютер не разделяет учеников: для эксперимента используйте отдельные профили браузера. Несколько одновременно открытых вкладок не синхронизируются, последняя запись может заменить изменения другой вкладки.

## Проверка перед защитой

На финальной версии прошли **95 тестов** (86 математических/модульных и 9 DOM-сценариев), проверка TypeScript и production-сборка Vite. После обновления зависимостей `npm audit` сообщает **0 известных уязвимостей**. Четыре запрошенных специализированных сканера не установлены; подробности — в SECURITY_AUDIT.md.

`npm test` выполняет математические и DOM-тесты. Для первых 60 задач ответы независимо вычисляются формулами/перебором; у двух задач с несколькими ответами отдельно проверены полные и неполные наборы. Проверяются все формулы KaTeX, ввод и сценарии изменения уровня. DOM-тесты проверяют фильтрацию, неверный/верный ответ, подсказки, сохранение, темы, достижения, ежедневный лимит и истечение таймера.

В текущем окружении нет доступного инструмента управления настоящим браузером. DOM-тесты не проверяют визуальные размеры, работу скачивания в Excel и поведение реального мобильного браузера. Перед защитой вручную проверьте:

- Главную и каталог на ширинах 375, 768 и 1440 px в обеих темах.
- Условие с формулой, неверный ответ, три подсказки, верный ответ и разбор.
- Перезапуск браузера с тем же адресом: сохранение статистики и оформления.
- Скачивание CSV и открытие в Excel.
- Олимпиаду на реальном устройстве, включая уход во фоновую вкладку.

## Ограничения

Приложение проверяет ответ, а не математическое доказательство. База небольшая, уровни не откалиброваны на учениках. Ответы находятся в клиентской сборке и доступны через инструменты разработчика: олимпиада предназначена для самопроверки, а не защищённого экзамена. Нет облачной синхронизации, аккаунтов и восстановления удалённых данных. Техническая работоспособность не доказывает педагогический эффект — эксперимент ещё предстоит провести.
